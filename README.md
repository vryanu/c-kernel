## C kernel/os written in asm & c

### Dependencies
Uses:
QEMU i386
NASM
i386 elf ld

### Features
* 2 stage boot into a protected mode
* 32 bit kernel
* keyboard interrupt handling
* inline arg parsing in shell
* shell commands
* VGA outputs
* basic IO function header
